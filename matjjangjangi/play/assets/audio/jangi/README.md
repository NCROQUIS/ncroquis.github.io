# 장기 배경음·효과음

2026-11-17 엔크로키 맞짱 장기용으로 직접 만든 원본 악곡과 합성 효과음이다. 외부 음원·연주·녹음·음성은 사용하지 않았다. 회사의 게임 리소스로 사용·수정·배포할 수 있다.

- `match-bgm.mp3`: 32초의 차분한 오음 음계, 현악기풍 발현음과 낮은 패드. 대국·관전·오늘의 문제에서 반복한다.
- `capture.mp3`: 낮고 짧은 두 겹의 목재 타격음, 0.5초.
- `check.mp3`: 두 음의 경고 종소리, 0.85초. 음성은 아니다.
- `victory.mp3`: 위로 올라가는 짧은 종결구, 2.4초.
- `defeat.mp3`: 낮아지며 가라앉는 종결구, 2.1초.

제작 원본은 `scripts/create-jangi-audio.py`다. 빌드 도구 Python·numpy·imageio-ffmpeg가 있으면 재생성할 수 있다. 재생 시에는 공용 NcqSound만 사용하며 외부 라이브러리·인코더가 필요하지 않다. 44.1kHz 스테레오 MP3 96kbps, 합계 약 448KB다. 음원 최대 피크는 0.62 이하이며 실제 게임은 추가로 음량을 낮춰 혼합한다.
