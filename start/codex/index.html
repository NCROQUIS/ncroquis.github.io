Codex로
시작해요

Codex를 쓰면 이 순서대로 해요. Codex에 엔크로키 킥오프를 한 번 연결해 두면 아이디어 말하기부터 테스트 링크, 출시까지 Claude와 같은 말로 할 수 있어요.

준비물

시작 전에 세 가지

  • CodexCodex 앱에 ChatGPT 계정으로 로그인해 둬요. 터미널을 쓰면 Codex CLI도 돼요 (아래 '명령어로 연결하기').
  • 회사 구글 계정@ncroquis.com 계정은 등록 없이 바로 써요. 회사 밖 분은 엔크로키 담당자에게 구글 계정 이메일을 알려 주세요. 등록되면 1분 안에 쓸 수 있어요.
  • GitHub 계정개발할 때 필요해요. 없으면 GitHub에서 무료로 만들어요.
  1. 1

    Codex에 엔크로키 킥오프 연결하기

    처음 한 번만 해요. 3분이면 돼요.

    먼저 이 주소를 복사해 둬요.

    https://kickoff-476465444216.asia-northeast3.run.app/mcp
    1. Codex 앱에서 설정을 열어요. 키보드로는 Ctrl + , (맥은 Cmd + ,)예요.
    2. 통합 → 플러그인 → MCP로 가서 추가를 눌러요.
    3. 종류를 Streamable HTTP로 골라요. 처음에는 STDIO로 되어 있어요.
    4. 이름 칸에 ncroquis-kickoff라고 적어요.
    5. URL 칸에 위에서 복사한 주소를 붙여 넣고 저장을 눌러요.
    6. 로그인할 브라우저가 열려요. 안 열리면 목록에 생긴 ncroquis-kickoff의 인증을 눌러요. Codex를 다시 시작하라고 나오면 먼저 다시 시작해요.
    7. 영어로 된 Allow Access 화면이 나오면 Allow Access를 눌러요.
    8. 구글 계정 고르기에서 회사 계정을 골라요. Authentication complete가 보이면 브라우저를 닫고 Codex로 돌아가요.

    메뉴 이름은 Codex 버전마다 조금 달라요. '통합'이 안 보이면 설정 왼쪽 목록의 'MCP 서버'에서 '서버 추가'를 눌러요.

  2. 2

    기다리는 시간 늘리기

    한 번만 해요. 1분이면 돼요.

    킥오프나 스토어 올리기처럼 1분 넘게 걸리는 일이 있어요. Codex는 기본으로 1분만 기다려서, 늘려 두지 않으면 일이 끝나기 전에 시간 초과(timed out)가 나와요.

    1. Codex 설정 폴더를 열어요. 윈도우는 파일 탐색기 주소창에 %USERPROFILE%\.codex를 붙여 넣고 Enter를 눌러요. 맥은 Finder에서 Cmd + Shift + G를 누르고 ~/.codex로 가요.
    2. config.toml 파일을 메모장(맥은 텍스트 편집기)으로 열어요.
    3. [mcp_servers.ncroquis-kickoff] 줄을 찾아 바로 아래 url 줄 다음에 이 한 줄을 넣어요.
      tool_timeout_sec = 600
    4. 저장하고 Codex를 다시 시작해요.

    파일 고치기가 어려우면 Codex에게 "내 Codex 설정에서 ncroquis-kickoff의 tool_timeout_sec를 600으로 바꿔 줘"라고 부탁해도 돼요.

  3. 3

    연결됐는지 확인하기

    10초면 돼요.

    Codex에서 새 대화를 열고 입력창에 /mcp를 쳐요. 연결된 서버 목록에 ncroquis-kickoff가 보이면 끝이에요.

    폴더(프로젝트)를 고르라고 하면 아무 폴더나 골라도 돼요. 킥오프는 내 PC 파일을 쓰지 않아요.

  4. 4

    아이디어 말하고 코드네임 고르기

    여기부터는 Claude와 같아요.

    새 대화에서 만들고 싶은 게임을 말해요. 생각나는 대로 한두 문장이면 충분해요.

    • 블록을 밀어서 펭귄이 지나갈 길을 만드는 퍼즐 게임 만들어 보자

    • 고양이를 모아 키우는 방치형 게임 만들어 줘

    Codex가 코드네임 후보 세 개를 보여 주면 "1번으로 할게"처럼 번호만 답해요. 1~2분 뒤 코드 저장소, 기획 시트, 소개 페이지 링크가 와요. 자세한 내용은 시작하기의 3·4단계와 같아요.

    패키지명은 스토어에 올린 뒤에는 바꿀 수 없어요. 고르기 전에 한 번 더 봐 주세요.

    Codex가 ncroquis-kickoff 도구를 써도 되는지 물으면 허용해요.

  5. 5

    Codex로 개발하기

    킥오프가 끝나면 같은 대화에서 "Codex로 개발할게"라고 해요. 레포를 내 PC에 받는 방법(git clone 주소)을 알려 줘요. 받은 폴더를 Codex에서 열면 Codex가 레포의 AGENTS.md(회사 개발 규칙)를 읽고 그대로 개발해요.

    테스트 링크와 구글플레이·토스 출시도 Codex에서 같은 말로 해요. 할 말은 출시하기 탭에 있어요.

    결과 맨 아래 'Claude Code에서 개발 시작' 링크는 Claude Code용이에요. Codex만 쓰면 넘어가도 돼요.

터미널

명령어로 연결하기

Codex CLI나 VS Code의 Codex를 쓰면 이게 더 빨라요.

codex mcp add ncroquis-kickoff --url https://kickoff-476465444216.asia-northeast3.run.app/mcp

실행하면 브라우저가 열려 바로 로그인해요 (1단계의 7·8번과 같아요). 안 열리면 터미널에 나온 주소를 브라우저에 붙여 넣어요. 나중에 로그인이 풀리면 codex mcp login ncroquis-kickoff를 실행해요.

Codex 앱, CLI, VS Code 확장은 같은 설정을 써서 한 곳에서만 연결하면 돼요. 기다리는 시간(2단계)도 같은 파일이에요.

막힐 때

자주 막히는 곳

시간 초과(timed out)가 나왔어요

서버는 하던 일을 끝까지 해요. 킥오프였다면 1~2분 뒤 "방금 킥오프 이어서 해 줘"라고 해요. 끝난 단계는 건너뛰고 결과를 보여 줘요. 빌드나 올리기였다면 "게임 이름 지금 상태 알려 줘"로 확인해요. 다음부터 안 나오게 2단계를 해 둬요.

'인증'을 눌러도 브라우저가 안 열려요

Codex를 다시 시작한 뒤 MCP 목록에서 다시 눌러 봐요. 터미널이 있으면 codex mcp login ncroquis-kickoff로도 로그인돼요.

'권한이 없어요'라고 나와요

개인 Gmail로 로그인했을 수 있어요. MCP 목록에서 ncroquis-kickoff를 지우고 1단계를 다시 해서 회사 계정을 골라요. 터미널에서는 codex mcp logout ncroquis-kickoff 다음 codex mcp login ncroquis-kickoff예요.

Codex가 킥오프 도구를 안 써요

입력창에 /mcp를 쳐서 ncroquis-kickoff가 있는지 봐요. 있으면 "엔크로키 킥오프로 해 줘"라고 콕 집어 말해요. 없으면 Codex를 다시 시작하고, 그래도 없으면 1단계를 다시 해요.

연결할 수 없다는 오류가 나와요

10초쯤 기다렸다가 다시 해 봐요. 쉬고 있던 서버가 깨어나는 중이에요.

회사 밖 사람인데 써도 되나요?

네. 엔크로키 담당자에게 구글 계정 이메일과 GitHub 아이디를 알려 주세요. 등록되면 1분 안에 쓸 수 있어요.

Claude와 같이 써도 되나요?

네. 같은 서버라서 Claude에서 킥오프하고 Codex로 개발해도 되고, 반대로 해도 돼요.
