# 숲빛 · 아이보리 · 골드 UI

2026-11-11 사용자 피드백의 `3-resources.zip`에 포함된 PNG 29종을 사용합니다.
원본 이미지와 투명 영역을 보존한 WebP 리소스입니다(이미지 전체 약 600KB).

로비의 배경·판·돌·아이콘뿐 아니라 프로필 패널·코인 캡슐·점수 칩·게이지·미션 버튼·챔피언십 배너·골드 주 버튼·하단 메뉴에도 제공된 리소스를 사용합니다. 문구·숫자·진행도는 한국어·영어로 코드에서 표시합니다.

`lobby-layout.js`의 SVG viewport가 PNG별 투명 여백을 보정합니다. 패널은 9분할하여 외곽과 모서리를 유지하고, 작은 화면에서 분할 경계가 보이지 않도록 안쪽 조각을 0.5 디자인 픽셀씩 겹칩니다. 로비의 배경에는 시안 색에 가까운 반투명 초록색을 겹칩니다. 원본 파일은 변형하지 않습니다.

제공된 PNG는 시안에서 잘라낸 레이어와 모양이 완전히 같지는 않습니다. 시안의 영역 좌표·크기·아이콘 위치를 기준으로 원본 PNG를 배치합니다. 측정 기준은 [로비 레이아웃 명세](../../docs/lobby-layout.md)에 있습니다.

글꼴은 Noto Sans KR의 가변 WOFF2를 로컬에 포함합니다. `fonts/noto-sans-kr.woff2`는 한글 전체와 앱에 필요한 영문·기호를 포함하며, 라이선스는 `fonts/OFL.txt`에 있습니다. 외부 폰트 서비스에 의존하지 않습니다.

실제 대국판과 돌 스킨에는 기존 격자·스킨·착수 연출을 계속 사용합니다.
