하고 싶은 일에 맞는 말을 Claude에게 하나만 하면 돼요. 빌드와 업로드는 Claude가 해요.

이렇게 말해요

하고 싶은 일마다 한 마디

적으면 아래 말에 그 이름이 들어가요. 한글 이름도 돼요.

  1. 휴대폰 브라우저로 바로 해 보기

    게임 이름 테스트 링크 만들어 줘

    1~3분 뒤 링크가 와요. 링크를 받은 사람은 누구나 휴대폰에서 바로 해 볼 수 있어요.

  2. 안드로이드 앱으로 테스트하기

    게임 이름 내부 테스트에 올려 줘

    구글플레이 내부 테스트에 올라가요. 테스터로 등록된 휴대폰의 플레이 스토어에서 받아요.

  3. 구글플레이에 업데이트하기 (실제 사용자)

    먼저

    게임 이름 정식 출시하자

    확인했으면

    게임 이름 프로덕션에 올려 줘

    먼저 비공개 테스트에 올라가요. 확인한 뒤 두 번째 말을 하면 실제 사용자에게 나가요. 두 번째는 관리자만 할 수 있어요.

중간에 Claude가 바뀐 점을 보여 주고 버전을 물으면 "추천대로 해 줘"라고 답하면 돼요.

알아 두면 좋은 것

처음 한 번, 그리고 막힐 때

구글플레이에 처음 올릴 때
Play Console에서 앱을 만드는 일이 한 번 있어요. Claude가 할 일을 순서대로 알려 줘요. 스토어 이미지는 웹 게임이면 Claude가 게임을 돌려 만들어 줘요.
토스
웹 게임이면 "게임 이름 토스에 올려 줘"라고 하면 토스 앱에서 열어 볼 QR까지 만들어 줘요. 처음 한 번은 앱인토스 콘솔에 앱을 등록해야 해서, "게임 이름 토스에 처음 내려고 해"라고 하면 등록 자료와 등급분류 자료를 모아 줘요. 검토 요청과 출시는 콘솔에서 해요.
막힐 때
Claude가 이유와 고치는 방법을 알려 줘요. 코드를 고쳐야 하면 그 내용을 Claude Code에 붙여 "이거 고쳐 줘"라고 해요.
