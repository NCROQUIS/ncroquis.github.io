게임 만들기,
여기서 시작해요

아이디어 한 줄이면 돼요. Claude에게 말하면 엔크로키 킥오프가 이름 짓기부터 코드 저장소, 기획 시트, 소개 페이지까지 차려 줘요. 개발을 몰라도 아래 순서대로 따라 하면 돼요.

준비물

시작 전에 세 가지

  • Claude 계정회사에서 받은 계정이 있으면 그걸 써요. 킥오프는 무료 플랜에서도 되고, Claude Code로 개발하려면 Pro·Max·Team·Enterprise 플랜이 필요해요.
  • 회사 구글 계정@ncroquis.com 계정은 등록 없이 바로 써요. 회사 밖 분은 엔크로키 담당자에게 구글 계정 이메일을 알려 주세요. 등록되면 1분 안에 쓸 수 있어요.
  • GitHub 계정개발할 때 필요해요. 없으면 GitHub에서 무료로 만들어요.
  1. 1

    Claude에 엔크로키 킥오프 연결하기

    처음 한 번만 해요. 3분이면 돼요.

    Claude 커넥터 설정 열기
    1. 목록에 '엔크로키 킥오프'가 있으면 연결을 눌러요. 회사에서 미리 추가해 둔 거예요.
    2. 목록에 없으면 추가(+ Add) → 커스텀 커넥터 추가(Add custom connector)를 눌러요. 이름은 '엔크로키 킥오프'로 적고, 주소를 붙여 넣은 뒤 계속해요.
      https://kickoff-476465444216.asia-northeast3.run.app/mcp

      로그인 설정을 물으면 '지금 로그인(Sign in now)'과 '자동 등록(Register automatically)'을 골라 추가해요.

    3. 영어로 된 Allow Access 화면이 나오면 Allow Access를 눌러요.
    4. 구글 계정 고르기에서 회사 계정을 골라요. 개인 Gmail을 고르면 권한이 없다고 나와요.

    '서버를 확인할 수 없습니다'가 나오면 10초쯤 기다렸다가 다시 해 보세요. 쉬고 있던 서버가 깨어나는 중이에요.

    Codex를 쓰면 Codex로 시작하기 탭의 순서대로 연결해요. 연결한 다음은 여기와 같아요.

  2. 2

    새 대화에서 아이디어 말하기

    생각나는 대로 한두 문장이면 충분해요.

    Claude에서 새 대화를 열어요. 입력창 왼쪽 아래 + 버튼 → 커넥터에서 '엔크로키 킥오프'가 켜져 있는지 확인하고, 만들고 싶은 게임을 말해요.

    • 출퇴근길에 한 손으로 하는 리듬 게임 시작하자

    • 고양이를 모아 키우는 방치형 게임 만들어 줘

    • 친구랑 번갈아 두는 오목 같은 게임 킥오프하자

    Claude가 장르, 핵심 재미, 누가 할 게임인지 같은 컨셉을 알아서 정리해요. 말하지 않은 부분은 기본값으로 채우고, 무엇을 정했는지 알려 줘요.

    Claude 대화에서 이미 만들어 본 게임이 있으면 새 대화 대신 그 대화에서 "이거 킥오프 프로젝트로 만들어 줘"라고 해요. 만든 코드가 레포에 같이 들어가요.

    처음 쓸 때 Claude가 도구를 써도 되는지 물어요. '항상 허용'을 누르면 다음부터는 묻지 않아요.

  3. 3

    코드네임 고르기

    Claude가 멈춰서 묻는 건 이것 하나예요.

    Claude가 후보 세 개를 보여 줘요. 영문 코드네임, 한글 가칭, 앱 패키지명이 함께 나와요. "1번으로 할게"처럼 번호만 답하면 돼요. 마음에 드는 이름이 없으면 직접 말해도 돼요.

    패키지명은 스토어에 올린 뒤에는 바꿀 수 없어요. 고르기 전에 한 번 더 봐 주세요.

    GitHub 아이디를 알면 같이 적어요. "1번, GitHub 아이디는 penguin-dev" 이렇게요. 그러면 레포에 바로 초대돼요.

  4. 4

    만들어진 것 확인하기

    고르고 1~2분 뒤에 대화로 링크가 와요.

    코드 저장소
    GitHub에 비공개 레포가 생겨요. AI가 읽는 개발 규칙과 컨셉 문서가 들어 있어요.
    기획 시트
    공유 드라이브에 프로젝트 폴더와 시트(개요, 할 일, QA)가 생기고 편집 권한이 공유돼요.
    소개 페이지
    이 사이트에 프로젝트 소개가 올라가요. 누구나 볼 수 있으니 비밀은 적지 않아요.
    레포 초대
    GitHub에서 초대 메일이 오면 수락해요. 회사 GitHub 조직 멤버는 바로 추가돼요.

    결과에 어느 계정으로 진행했는지도 나와요. 다른 계정이면 커넥터를 다시 연결해요.

  5. 5

    자유롭게 개발하기

    툴(Claude Code, Codex 등)을 사용해서 자유롭게 개발하세요.

    가장 쉬운 방법은 결과 맨 아래 'Claude Code에서 개발 시작'을 누르는 거예요. 레포와 첫 요청이 채워진 Claude Code가 클라우드에서 열려서, 보내기만 누르면 시작해요. 내 PC에 내려받거나 폴더를 만들 필요가 없어요.

    폴더를 고르라고 나오면 입력창 아래 맨 앞의 환경 고르기(로컬·Local)를 눌러 클라우드(Cloud)를 골라요. 링크를 크롬 같은 웹 브라우저에서 열어도 돼요 (레포까지 채워진 채로 열려요).

막힐 때

자주 막히는 곳

'권한이 없어요'라고 나와요

개인 Gmail로 로그인했을 수 있어요. 커넥터 설정에서 연결을 끊고 다시 연결해서 회사 계정을 골라요.

회사 밖 사람인데 써도 되나요?

네. 엔크로키 담당자에게 구글 계정 이메일과 GitHub 아이디를 알려 주세요. 등록되면 1분 안에 쓸 수 있어요.

대화에서 엔크로키 킥오프가 안 보여요

입력창 왼쪽 아래 + 버튼 → 커넥터에서 켜져 있는지 확인해요. 목록에 없으면 1단계를 다시 해요.

레포 초대를 건너뛰었다고 나와요

GitHub 아이디를 몰라서예요. 같은 대화에서 "내 GitHub 아이디는 penguin-dev야"라고 말하면 초대만 추가돼요.

Claude Code를 열었더니 폴더를 고르라고 나와요

내 PC 폴더는 필요 없어요. Claude 앱의 새 작업이 '로컬'로 열린 거예요. 입력창 아래 맨 앞의 환경 고르기를 눌러 클라우드(Cloud)를 고르고, 레포가 비어 있으면 바로 옆에서 프로젝트 레포를 골라요. 'Claude Code에서 개발 시작' 링크를 크롬 같은 웹 브라우저에서 열면 레포까지 채워진 채로 열려요.

Claude 대화에서 만든 게임을 프로젝트로 옮기고 싶어요

그 대화에서 "이거 킥오프 프로젝트로 만들어 줘"라고 해요. 대화에서 만든 코드가 레포에 같이 들어가요. 이미 킥오프했다면 같은 대화에서 "만든 코드를 내 프로젝트 레포에 넣어 줘"라고 하면 돼요. Claude Code는 다른 대화를 볼 수 없어서, Claude Code에 "옮겨 와 줘"라고 하면 못 가져와요.

Claude Code에서 GitHub 연결 버튼이 안 나와요

회사 Claude(Team)를 쓰면 관리자가 조직 설정 → 커넥터에서 GitHub를 켜 둬야 해요. 담당자에게 부탁하고, 켜진 뒤 Claude Code 페이지를 새로 고쳐요.

Claude Code에서 레포가 안 보여요

GitHub 초대 메일을 수락했는지 확인해요. 그래도 안 보이면 담당자에게 회사 GitHub 조직에 Claude GitHub 앱이 설치돼 있는지 물어봐요.

테스트 링크가 안 열리거나 화면이 하얘요

처음 올린 뒤 1~2분은 기다려요. 그래도 안 되면 Claude가 알려 준 오류를 Claude Code에 그대로 붙여 "이거 고쳐 줘"라고 해요. 이미지나 스크립트 주소가 /로 시작하는 게 흔한 원인이에요.

Unity로 만들고 싶어요

아이디어를 말할 때 "Unity로 만들자"를 붙여요. 말하지 않으면 웹 기술로 시작해요.

이름을 바꾸고 싶어요

고르기 전이면 다른 후보를 고르거나 원하는 이름을 말하면 돼요. 고른 뒤에는 패키지명이 정해져서 새로 킥오프해야 해요.

이미 킥오프한 프로젝트를 고치고 싶어요

새 대화에서도 "게임 이름 엔진을 Unity로 바꿔 줘"처럼 게임 이름(코드네임)과 바꿀 것만 말하면 돼요. 말하지 않은 건 그대로 둬요.

불편한 점이나 아이디어를 알리고 싶어요

Claude에게 "방금 일 피드백으로 보내 줘"라고 말해요. Claude가 대화 내용을 정리해서 관리자에게 보내요. 나중에 "내 피드백 어떻게 됐어?"라고 물으면 처리 상태와 관리자 답변을 알려 줘요.
